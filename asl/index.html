ASL recognition app

A web app that recognizes American Sign Language in a live video feed and shows the matching letter or word on screen. Built for the Congressional App Challenge, District NJ-01.

Nov 2024
  • YOLOv8
  • Roboflow
  • Computer vision
  • Web app

What I did

I owned the model end to end, from raw images to a working app.

  • Prepared and annotated the full image dataset in Roboflow.
  • Trained a custom YOLOv8 object detection model on it.
  • Deployed the model in a web app that detects signs in live video.
  • Tested with Deaf community members and refined the model to meet real accessibility needs.
