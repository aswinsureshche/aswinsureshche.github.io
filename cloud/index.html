Cloud misconfiguration lab

An AWS environment in Terraform with four deliberate security flaws. One variable, harden, flips every resource between vulnerable and hardened, so the same scanners can measure the difference.

Scan, harden, re-scan

The same two scanners run against both states, and a script compares the reports.

  1. Deploy vulnerablebaseline stateharden=false
  2. ScanProwler + ScoutSuiterun_prowler.sh
  3. Hardensame resources, fixedharden=true
  4. Re-scansame checksrun_scoutsuite.sh
  5. Comparewhich findings closed, which remaincompare_reports.py
  6. Tear downand verify nothing is leftverify_teardown.sh

Cost guardrail

An AWS Budgets alarm emails at 80% and 100% of a monthly limit, so a forgotten lab can’t run up a bill. The limit is a variable, $5 by default.
